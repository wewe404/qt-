# 带键盘事件的计算器（实验 1）

## 功能
- 四则运算（加、减、乘、除），支持小数
- 按键布局参考 Windows 计算器：`%`、`CE`、`C`、`⌫`、`1/x`、`x²`、`√x`、`+/−`、`0`–`9`、`.`、`=`、`÷ × − +`
- 键盘输入（与鼠标点击复用同一套逻辑）：
  - `0`–`9`、`.` 输入数字
  - `+ - * /` 四则运算，`Enter` / `=` 计算
  - `Backspace` 退格，`Esc` 清除（C），`Delete` 清除当前项（CE）
  - `%` 百分号，`r` 倒数（1/x），`q` 平方（x²），`Shift+2` 开方（√x），`F9` 正负号（+/−）
- 边界处理：除数为 0、倒数为 0、负数开方、连续小数点、连续运算符、计算结果后继续输入

## 构建
用 Qt Creator 打开 `Calculator.pro`，选择 Qt 6.9.2 MinGW 64-bit 套件构建运行。

## 文件说明
- `calculator.ui`：界面布局（Qt Designer 可直接打开）
- `calculator.h/.cpp`：计算器状态管理与事件处理
- `style.qss`：界面样式表（浅色 Windows 计算器风格）
